# Snake Game (C++)

## Overview

Snake Game is a console-based implementation of the classic Snake Game developed in C++. The game uses object-oriented programming concepts, real-time keyboard input, collision detection, dynamic memory allocation, and score tracking.

## Features

* Real-Time Snake Movement
* Food Generation
* Score Tracking
* Collision Detection
* Screen Wrapping
* Dynamic Snake Growth
* Keyboard Controls (W, A, S, D)
* Object-Oriented Design

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* Dynamic Memory Allocation
* Arrays
* Classes and Objects
* Windows Console API

## Controls

* W → Move Up
* A → Move Left
* S → Move Down
* D → Move Right
